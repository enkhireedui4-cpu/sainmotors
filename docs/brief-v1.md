# Sain Motors V1 — нэгдсэн бриф (сайжруулсан prompt)

Шинэчилсэн: 2026-10-15. Анхны англи prompt болон «Сайн Моторс — нэгдсэн V1 төлөвлөгөө»-г нэгтгэж,
хоорондын зөрчлийг шийдсэн хувилбар. Зөрчил гарвал энэ баримт давамгайлна. Шинэ AI/хөгжүүлэгчийн
session-д энэ файлыг prompt болгон өгнө.

---

## Үүрэг

Sain Motors-ын албан ёсны байгууллагын вэбийг (sainmotors.mn) хариуцсан ахлах продакт дизайнер ба
full-stack инженерээр ажилла. Код `Desktop/sainmotors.mn` дотор. Ажиллаж буй код, локал preview,
шалгалтын үр дүн хүлээлгэж өг — зөвхөн зөвлөмж биш.

## Зорилго

Компанийг ойлгуулах → брэндүүдийг танилцуулах → үйлчилгээ/сервисийг харуулах → зөв баг руу холбох.
Брэнд бүрийн дэлгэрэнгүй нь тухайн брэндийн сайтад (jetour.mn ажиллаж байна; chery.mn удахгүй — DNS
байхгүй үед холбоос тавихгүй). Цаашид брэнд бүрд тусдаа сайт нэмэгдэнэ.

V1-д ОРОХГҮЙ: каталог, үнэ, үзүүлэлт, харьцуулалт, үлдэгдэл, тест драйвын захиалга, CRM, CMS,
бүртгэл, төлбөр, analytics-ийн нэгдсэн хэмжилт. Форм — privacy/хүлээн авагч батлагдаагүй тул байхгүй;
утас, имэйлээр.

### Hero дүрэм

- Өндөр ≈ 88svh; mobile-ийн хувьсах өндөр, гарчиг/товч багтана. Босоо дэлгэцэнд (утас, таблет) тусдаа тайралт.
- Slide бүр: богино MN/EN гарчиг, нэг өгүүлбэр, нэг CTA. Эхнийх «Брэндүүдтэй танилцах». Зурган дотор текст шингээхгүй.
- 6 сек, зөөлөн fade, 4 сонгогч, сум, swipe, pause. Keyboard focus орох, гараар сонгох, pause дарахад бүрмөсөн зогсоно; reduced-motion үед өөрөө эхлэхгүй. Hover, нуугдсан tab — түр зогсолт.
- Эхний зураг өндөр priority-тэй HTML-д. Дараагийнх нь хуудас ачаалсны дараа, нэг slide урьдчилан, бага priority-гаар. Ачаалаагүй зураг руу хэзээ ч шилжихгүй.
- Брэндийн зураг ашиглавал брэндийн нэр, холбоосыг харуулна.

## Агуулгын дүрэм

- Бүх бичвэр `src/content/`-д `status`-тэй: `approved` / `sourced` / `draft`.
- Зохиохгүй: брэнд, дистрибьюторын эрх, түүх, тоо, сэтгэгдэл, шагнал, хаяг, утас, баталгаа.
- Ноорогоор бүтцээ барина; гэхдээ `npm run build:release` нь `approved`-аас бусад бүх зүйл, дутуу логог
  жагсааж зогсооно. Хоосон хэсэг, эвдэрсэн зураг, placeholder нийтлэхгүй.
- Дашням ахлахын хүснэгт: `npm run content:checklist` → `docs/content-checklist.csv`
  (хэсэг → MN → EN → зураг/лого → хийсэн хүн → батлагч → төлөв).

## Хүлээн авах шалгуур

- 360 / 390 / 768 / 1440 px: overflow үгүй, hero тайралт зөв, бүх цэс/CTA ажиллана.
- Хэл солих, mobile цэс (Esc, focus буцах), брэндийн route, гадаад холбоос, tel/mailto/чиглэл.
- Keyboard + харагдах focus, reduced-motion, console алдаагүй, CLS 0.
- Хуудас бүр: зөв `lang`, title/description, өөрийгөө заасан canonical, харилцан hreflang + x-default; sitemap, robots, 404.
- `npm run typecheck`, `lint`, `test`, `build`, `test:e2e` бүгд ногоон. Build амжилттай = харагдац шалгасан гэсэн үг биш — screenshot-оор нягтална.
